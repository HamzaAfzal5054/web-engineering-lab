# Web Engineering Lab 01

A minimal web project created for Lab 01: Setting Up Your Web Engineering Development Environment.

## Commands

- `npm install` installs the development tools.
- `npm test` runs the test with Node's built-in test runner.
- `npm run lint` checks JavaScript with ESLint.
- `npm run format` checks formatting with Prettier.
- `npm start` serves the `public` directory locally.

After starting the server, open the URL printed in the terminal. The page displays `Hello, World!`, generated by the reusable `greet` function.
